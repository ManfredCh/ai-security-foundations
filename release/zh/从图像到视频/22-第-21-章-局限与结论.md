时效与外推局限：2025—2026 预印本、权重、许可和产品可用性会漂移；闭源系统只支持接口层结论；治理证据受法域与执行环境约束。事件表是截至 2026-08-09 的快照，不估计发生率或未来走向。

- RQ1：技术转折来自表示、状态更新、条件与时间接口重组；231 条规范边是当前可审计谱系，不是因果网络。

- RQ3：像素、连续 latent、离散 token 和时空 codec 决定信息与计算上限，必须与重建和系统代价共报。

- RQ5：视频瓶颈由表示容量、更新粒度、历史机制和动作/时序监督共同决定，单帧画质不足。
- RQ6：统一至少需要共享参数、表示或目标；图像预训练或同品牌 API 不等于机制统一或无负迁移。
- RQ7：只有任务、数据、输出、采样、评测、硬件和统计合同一致的子集可比较。
- RQ8：少步、缓存、量化、并行和 codec 改变不同局部成本；端到端 trace 缺失时不宣称服务收益。
- RQ9：纠错后 core 74、branch 32；角色由 A—E 规则和可核后继决定，不由热度决定。
- RQ10：数据谱系、输出凭据、水印、平台传递、组织控制和申诉纠错需组合，单层不能证明真实性、合法性和安全。
- RQ11：34 条事件支持时间受限生态解释，不支持采用率、影响率或算法性能结论。
